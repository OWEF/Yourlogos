# Discover integration v1.7

The canonical encounter-v1.html shell now adapts semantic/1.2 configurations and packets through the existing Expression Engine. The same intro, controls and three-section result templates serve the new semantic encounters. No mathematical/inference rule was changed. Historical Dillard/Kierkegaard controls and results remain regression-tested in the original edition.

Consumer entry: experiments/discover-v17.html. Select a fixture via #encounter=money, workshop, apology or evidence in review links, not developer dropdowns. Consumer DOM contains no founder controls. Research entry: experiments/discover-v17-qa.html has scenario buttons, all four readings and packet/source traces. This is a separate public research file, not authenticated access: there is no private data or security promise.

Trade-Off now records a first allocation, displays its computed resource conversion or joint output, and allows reconsideration before reveal. Actual resource feasibility comes from the same kernel. Decision editing retains the prefix and invalidates subsequent choices. Infeasible/unsupported results return a recoverable explanation, not an empty final screen. The result question is the final user-facing content.

The v1.2 research harness used raw number inputs, configuration dropdowns and JSON targets. The consumer edition reuses the established dark ivory/gold/sage Discover shell, readable quotation/scenario pairing, native range controls, progressive decisions and editorial three-section reading. Research content is available only in its dedicated edition. There is no new UI system or production route.

## Remaining limitations

The semantic engine retains its documented v1.2 limitations: narrow wording differences among modes, structural rather than unrestricted semantic branch validation, and curated source mappings. Dillard/Kierkegaard retain their legacy prose lengths; the 45–70-word gate applies to semantic packets. Reconsideration shows the model's consequence but does not assert a new external event. The implied philosophical salience of each derived fact still needs independent human review. A source-faithful analogy is not guaranteed merely by passing schema/tests. No deployment, account integration, paid model or production change.
