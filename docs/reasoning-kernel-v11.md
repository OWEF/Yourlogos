# Discover · Reasoning Kernel 1.1

## What transferred

Four data-only quotation records use the same evaluator, expression interface and UI. Each specifies a quoted passage and locator, an interpretive relation, mechanism, operation, assumptions, scenario, constraints or transitions, and an excluded inference. The kernel does not select a mechanism from raw prose. A new quotation needs source research, a faithful model and editorial review.

Trade-Off supports any number of integer-valued choices, multiple linear resource constraints, adjustable capacities, exact budgets and optional spending. A weighted sum represents conversion; a weighted minimum represents complementary inputs. Each calculation recomputes feasibility and tests adding a unit with spare capacity or moving one unit between choices. The alternatives are local probes, not a global optimum. A rise in output is not a judgment about the reader’s priorities.

Decision Map traverses a finite acyclic graph. Each step records available alternatives, facts available before acting, later disclosures, current commitments, revisions and closed options. Editing a prefix discards downstream evidence. Revising a choice in the interface is distinct from an irreversible act inside the scenario. Missing information, incomplete paths, unmet prerequisites, and invalid allocations yield no reading. The pilot does not resolve stochastic futures, arbitrary cycles or unrestricted symbolic logic.

| [Descartes, Discourse II](https://en.wikisource.org/wiki/Discourse_on_the_Method/Part_2) · [SEP on Descartes](https://plato.stanford.edu/entries/descartes/) | One to three decisions about reporting a disputed figure; grounds for assent can change before printing | A practical decision about publication can be made while judgment about a figure is suspended. | Documentary corroboration illustrates restraint in assent, distinct from Cartesian certainty. The sources were checked against independent published scholarship. These particular scenario interpretations have not received independent human editorial approval.

## Contract and compatibility

A ready reasoning/1.1 packet preserves selected inputs, quote identity, source, mechanism fit, structure, distinction, assumptions, necessary and conditional claims, exclusions and question. Necessity is relative to the stated model. The expression boundary checks the packet version, evidence class and backing for the headline and source explanation, and excludes unsupported claims. Four transfer records use the existing expressive layer’s reflective fallback. The original Dillard and Kierkegaard adapters retain their more specific semantic rules and four-voice coverage while calling the shared structural kernel first. Seneca and Woolf retain their original control coverage and are exercised through the structural adapter. Their historical UI is outside this preview.

## Founder checklist

- Compare Smith at 3 press / 1 binder and at 2 / 2. Check whether the result communicates joint production beyond reporting a count.
- Compare Descartes publishing the first report with requesting minutes and revising a provisional figure. Judge whether the documentary analogy is defensible.
- Review all four source mappings and decide which merit inclusion in the Context Atlas. These transfer records carry no editorial approval.
- Review before/after mobile screenshots and try the long Thoreau passage, editing a route, and a real iPhone with VoiceOver and Reduce Motion.
- Observe first-time readers explaining the passages in their own words. Automated checks establish structural behavior, not learning.
